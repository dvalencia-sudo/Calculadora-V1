# Basic Calculator V1

A simple calculator built with plain HTML, CSS, and vanilla JavaScript.

## Description

This project is a basic calculator that performs the most common arithmetic operations: addition, subtraction, multiplication, division, and percentage calculation. It is a lightweight frontend app designed to practice DOM manipulation and event handling in JavaScript.

## Features

- Basic arithmetic operations
- Clear button to reset the display
- Decimal input support
- Responsive layout for desktop and mobile screens
- Simple and clean user interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Open the project folder.
2. Open `index.html` in a browser.
3. Use the calculator normally.

## Project Structure

- `index.html` — calculator layout
- `style/style.css` — styling and visual design
- `js/script.js` — calculator logic

## Notes

This is a beginner-friendly project intended to demonstrate how a small web app can be built using only native web technologies.
